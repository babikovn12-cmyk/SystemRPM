# System RPM

## Русский

**System RPM** — Windows-инструмент для автоматизации игровых маршрутов на сервере RPM. Приложение позволяет записать и воспроизводить маршрут с клавишами WASD, пробелом и движением мыши, а также настроить горячие клавиши для ручного и автоматического режимов.

В режиме стамины программа следит за выбранным игровым логом. При появлении сообщения об остановке и отдыхе для указанного персонажа она приостанавливает маршрут на заданное время, а затем продолжает его. Также доступен отдельный режим воспроизведения движений для анти-АФК.

### Возможности

- Калибровка маршрута с пятисекундным обратным отсчётом.
- Захват WASD, пробела и движения мыши.
- Ручной запуск и автоматическое воспроизведение маршрута.
- Обнаружение сообщения об отдыхе по имени персонажа в новых строках игрового лога.
- Настраиваемая длительность отдыха и горячие клавиши.
- Отдельная калибровка и режим анти-АФК.

Приложение рассчитано на Windows. Используйте его только в соответствии с правилами сервера RPM.

## English

**System RPM** is a Windows utility for automating gameplay routes on the RPM server. It can record and replay routes using WASD, Space, and mouse movement, with configurable hotkeys for manual and automatic modes.

In stamina mode, the application watches a selected game log. When a new log entry reports that the configured character needs to stop and rest, the route pauses for the selected duration and then resumes. A separate anti-AFK mode replays calibrated mouse movement.

### Features

- Route calibration with a five-second countdown.
- WASD, Space, and mouse-movement capture.
- Manual playback and automatic route replay.
- Rest-message detection by character name in new game-log entries.
- Configurable rest duration and hotkeys.
- Separate calibration and anti-AFK mode.

The application targets Windows. Use it in accordance with the RPM server rules.
